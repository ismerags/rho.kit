This is a starter post so the site has something to show on day one. Edit it on
github.com — open content/builds/2026-09-current-build.md, click the pencil
icon, change the lines above the dashes, and commit. The site rebuilds itself in
about two minutes.

Add the `set:` line with a set number and this post will link straight to that
set's price page. Add `instagram:` with a post link and a button appears.

When the build is done, change `status: building` to `status: complete` and it
moves down into the finished list.
